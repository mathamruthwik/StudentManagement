# Student Management System

A small HTML, CSS, and JavaScript project for the practical assignment:
**Compare GitHub, GitLab, and Bitbucket by managing a sample software project.**

## Features
- Add student name, roll number, and department
- Display student records
- Delete a student record
- Basic required-field and duplicate-roll-number validation

## Run the project
1. Extract the ZIP file.
2. Open `index.html` in a web browser.
3. Add a few sample student records.

No installation or server is required. This is a frontend-only demo; records are stored in memory and reset when the page is refreshed.

1. Creating a repository
